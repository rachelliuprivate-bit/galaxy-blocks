# 上新 Studio 电商内容工作台

课程《构建可交互的产品原型》的实践作品。使用 HTML、CSS、原生 JavaScript 和随项目提供的 JSZip；静态托管，无真实 AI 调用和后端。

## 运行

下载本目录的文件后打开 index.html；所有资源均使用相对路径，也可由静态网站服务托管。无需安装依赖。工作台提供创作、模板、素材、说明四个导航视图。

single-page.html 是隐藏侧边导航的核心流程演示入口，与完整版共享逻辑和浏览器数据，并非独立保存的历史版本。

## 核心功能

手工录入商品及 JPG/PNG/WebP 图片、参考链接与截图；读取 .xlsx 第一工作表或 UTF-8 CSV；最多 30 件商品；模拟加载；规则生成文案与 Canvas 主图；编辑和 PNG/CSV 导出；保存整套、标题或卖点模板；模板搜索、店铺标签和新商品复用；素材保存和再次使用；LocalStorage 保存。

## 数据限制

数据仅在当前浏览器，不跨设备同步；未提交表单不会保存。草稿保留最近 90 份。图片最大 8 MB，读入后缩放。表格最大 2 MB，解压总量最多 12 MB。不支持 .xls、表内图片、公式计算和读取远程图片。参考网页与参考截图仅保存，不用于自动分析。图片不抠图。导入商品后需要手动补图，勾选保存素材才会入素材库。

模板将识别到的商品字段转为占位符，保留排版配色。自由改写的固定文本可能仍需人工清理。主图自定义短句在复用时按新商品字段重建。下一步应先完善模板参数化，再接入真实模型。

## 后续 AI 扩展

将 generate 中规则组合部分提取为生成服务接口；通过服务器端调用文本或图像模型，返回结构化草稿；密钥留在服务器，不写入前端。图片生成需使用商品原图作为条件并由人工核验商品外观。现有页面保留编辑、失败、重试与人工复核环节。

## 校验

通过 node --check；在浏览器实测了示例生成、编辑、模板收藏和搜索、新商品替换、Excel/CSV 导入、缺失字段提示、PNG/CSV 下载与刷新保留。浏览器已验证主要用户流程；手机实机、大规模数据和所有边界场景尚未全面验证。真实运营访谈、用户意愿与效率提升尚未验证。

JSZip 的许可证见 JSZIP-LICENSE.md。示例商品插画为代码绘制，仅作课程演示。

## 发布状态与 GitHub Pages

作品代码发布在本仓库的 `shangxin-studio/` 目录。GitHub 代码页面展示的是源码，不会直接运行网页。

当前仓库尚未开启 GitHub Pages。若选择从 `main` 分支的 `/(root)` 发布，工作台位于网站的 `/shangxin-studio/` 子路径。开启 Pages 后，以 GitHub Settings → Pages 显示的实际地址为准。

## 数据与依赖

网站不调用外部 AI 服务，不收集访客输入；商品、模板和草稿保存在各自浏览器。仓库只包含课程原型代码和虚构示例商品，没有 API 密钥或个人商品数据。

内附 JSZip，用于读取 .xlsx；许可证见 JSZIP-LICENSE.md。JSZip 不需要从第三方 CDN 加载。
