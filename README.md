# 星际方块：银河消除 · Galaxy Blocks

## 第一次打开

1. 下载 Galaxy-Blocks.zip，在电脑上解压整个压缩包。
2. 打开 dist 文件夹，双击 index.html。Chrome、Edge 或 Firefox 均可打开。请把同目录下的 CSS 和 JS 文件放在一起。
3. 选“经典模式”或“银河挑战”，点击“开始游戏”。手机可打开在线版本，使用屏幕底部的操作按钮。

## 怎么玩

左右移动、旋转方块，把一整行填满即可消除。虚线表示落点，空格会把方块直接锁定在那里。上方空间不足以生成新方块时，本局结束。暂停后可以继续，或返回模式选择并放弃本局。

| 按键 | 操作 |
| --- | --- |
| ← / → | 左右移动，可长按 |
| ↓ | 软降，可长按 |
| ↑ 或 X / Z | 顺时针 / 逆时针旋转 |
| 空格 | 硬降，立即锁定 |
| C | 暂存或交换，每个方块限一次 |
| P | 暂停或继续 |
| F | 银河挑战满能量时释放星际冲击 |

每袋随机包含全部七种方块，各出现一次。每消除 10 行升一级。一次消除 1、2、3、4 行分别获得 100、300、500、800 分乘以当前等级。连续两次落子均消行，从第二次开始每多一次连击增加 50 分乘以等级。软降每格加 1 分，硬降每格加 2 分。

银河挑战中每消一行获得 18 点星能，每次连击另加 8 点乘以额外连续次数，一次四行再加 20 点。达到 100 点时按 F，或点亮起的星能按钮，清除最底部有已锁定方块的一行。技能不会增加分数、行数或连击。

最高分按模式分别保存在当前浏览器。在线版与下载版的纪录分别保存；清理浏览器数据可能清除纪录。右上角可关闭音效。切换窗口会自动暂停。

## 文件与修改

- dist/index.html 是游戏入口与中文界面。
- dist/style.css 控制配色、布局和手机适配。
- dist/engine.js 管理形状、七袋随机、旋转踢墙、计分和星能。
- dist/art.js 绘制原创行星、星环、地形和移动星空。
- dist/game.js 处理键盘触屏、音效、画面和纪录保存。
- rules.test.js 是可重复运行的规则测试。已安装 Node.js 的开发者可在项目目录执行 node --test rules.test.js。玩游戏无需安装 Node.js。

## 部署

把 dist 文件夹内的全部文件上传到静态网页托管服务，选择 index.html 为网站首页即可。无需安装依赖或构建。

## 单人和双人

首页先选择游戏人数。单人游戏保留经典与银河挑战，并扩大了中央棋盘。双人是同一台电脑、同一把键盘的本地对战。两边同时开始，收到相同顺序的七袋方块，各自计分。先堆到顶的一方落败。P 暂停双方，暂停后可切回单人。

| 操作 | 玩家 1 | 玩家 2 |
| --- | --- | --- |
| 左右 / 软降 | A、D / S | 左右键 / 下键 |
| 顺转 / 逆转 | W / Q | 上键 / 斜杠 |
| 硬降 / 暂存 | 空格 / E | 回车 / 右 Shift |

## 背景音乐

《星环慢航》是一段由浏览器实时合成的原创循环乐曲。默认开启，第一次点击模式或开始游戏后响起。单人、双人、暂停和结算界面共用同一段音乐。切换到其他标签页会静音。右上角的「♫ 音乐」开关和操作音效可以分别设置，下次打开会记住选择。离线运行也能播放。
