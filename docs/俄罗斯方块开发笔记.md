# 俄罗斯方块开发练习：从空文件夹到可玩的游戏

这份笔记记录了本次在 VS Code 中完成俄罗斯方块练习的过程。项目使用 HTML、CSS、JavaScript 和 Canvas，不依赖外部游戏框架或音频文件，适合零基础读者按步骤阅读。

## 项目结构

```text
practice/
├── index.html    页面结构和中文操作界面
├── styles.css    蓝黑色星际主题、布局和按钮样式
├── game.js       Canvas 绘制、方块规则、输入和背景音乐
├── server.js     使用 Node.js 内置模块提供本地网页
└── package.json  项目名称和启动命令
docs/
└── 俄罗斯方块开发笔记.md
```

游戏使用 10 列、20 行的棋盘，包含七种标准方块、自动下落、移动、旋转、软降、硬降、满行消除和计分。页面适配桌面和窄屏，并提供触屏操作按钮。

## 开发过程

### 1. 从空文件夹创建基础版

先搭建 HTML 页面、CSS 外观和 Canvas 棋盘，再用 JavaScript 实现方块生成、碰撞检测、锁定、消行和得分。使用七袋随机，让每组方块都包含七种形状各一次。

### 2. 启动本地网页

项目使用 Node.js 内置的 HTTP 模块提供静态文件，不需要安装服务器依赖。服务器启动后，在浏览器打开：

```text
http://localhost:4173/
```

开发时 PowerShell 阻止了 `npm` 的脚本入口 `npm.ps1`，因此没有修改系统执行策略或额外安装工具，而是直接用 Node.js 启动：

```powershell
node server.js
```

### 3. 增加暂停、继续和取消本局

- 点击“暂停”或按 **P** 暂停；暂停时下落和方块操作停止。
- 点击“继续”或再次按 **P**，从原来的棋盘状态继续。
- 点击“取消本局”会先询问确认；确认后清空得分和棋盘并回到开始界面，取消确认则保留当前进度。
- “重新开始”会立即开始一局新游戏。

### 4. 增加浏览器合成的背景音乐

音乐由 Web Audio API 实时合成，使用缓慢的和弦、柔和的旋律音和延迟回声，按和弦序列循环播放，不需要下载音乐文件。点击开始游戏后播放；暂停时静音并停止当前音符，继续后恢复；取消本局或游戏结束时停止。

界面提供背景音乐开关和音量滑块，默认音量为 **35%**。音乐使用单一音频上下文和一个循环调度器，暂停、继续或重新开始不会创建重叠的播放序列。若浏览器不支持 Web Audio API，界面会提示“音频不可用”，但游戏仍可进行。

### 5. 增加消行特效

消除整行时，棋盘上会显示短暂的蓝白扫光，并散出与方块颜色相同的粒子。每行生成 30 个粒子，特效约 **0.72 秒**后消散。消行和计分仍按原规则立即完成，特效只负责绘制，不改变游戏逻辑。

## 本次检查结果

- `node --check game.js` 和 `node --check server.js` 语法检查通过。
- 本地主页及 CSS、JavaScript 文件可正常访问，HTTP 状态为 **200**。
- 浏览器操作验证了开始、暂停、继续、取消确认、重新开始和音乐开关。
- 模拟浏览器不支持 Web Audio API 时，游戏仍进入进行中状态。
- 消行测试中，满行被清除、行数增加 1、得分增加 100 分；特效生成 30 个粒子，并在约 0.72 秒后消失。

以上是本次实际完成和检查的内容；没有把未执行的测试记录为通过。

## 如何运行

1. 在 VS Code 中打开 `practice` 文件夹。
2. 打开终端并运行：

   ```powershell
   node server.js
   ```

3. 在浏览器打开 `http://localhost:4173/`。
4. 点击“开始游戏”后即可开始游戏和播放背景音乐。
